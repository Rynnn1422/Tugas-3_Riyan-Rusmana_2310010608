## Deskripsi
Tugas ini merupakan pembuatan website sederhana menggunakan HTML dan CSS yang menampilkan formulir dan tabel. Website dibuat untuk mempraktikkan penggunaan elemen HTML dalam menerima input pengguna dan menyajikan data secara terstruktur.

## Struktur File
- `index.html` — Berisi struktur halaman website, formulir, dan tabel data.
- `style.css` — Berisi pengaturan tampilan website agar lebih rapi dan menarik.

## Fitur Website
1. Menampilkan formulir input data.
2. Menggunakan berbagai elemen formulir HTML.
3. Menampilkan data dalam bentuk tabel.
4. Menggunakan CSS eksternal untuk mengatur tampilan halaman.
5. Mengatur warna, ukuran teks, jarak, dan tata letak agar mudah dibaca.

## Teknologi yang Digunakan
- HTML5
- CSS3

## Cara Menjalankan
1. Buka folder `tugas3_2310010608`.
2. Klik dua kali file `index.html`.
3. Website akan terbuka melalui browser seperti Google Chrome atau Mozilla Firefox.

## Tujuan

Tugas ini bertujuan untuk memahami penggunaan formulir dan tabel dalam HTML serta penerapan CSS untuk mempercantik tampilan halaman website.
